# v1.2.0

个人双端同步记账系统 —— **离线优先、双端同步**（Android 手机端 + JavaFX 电脑端 + Spring Boot 云端同步服务）。

本次是**功能版本**：新增「周期记账（自动续费 / 固定收支）」，到期生成待确认清单、确认后才入账；同时修掉上一个版本里几个会被实际使用踩到的问题（重置后默认数据不回来、桌面端版本号显示错误）。

## 本次更新（v1.2.0）

### 新增：周期记账（自动续费 / 固定收支）——两端 + 后端

给房租、月供、各类会员这类「每隔一段时间固定一笔」的收支建一条规则，不用每月手动录。

- **规则字段**：名称、金额、支出/收入、分类、账户、备注 + **间隔（每 N 天 / 周 / 月）** + 首次日期。
  - 用户常说的「30 天续费一次」直接填 `30 天`；每周固定则填 `1 周`；每月固定填 `1 月`。
  - 每月规则按首次日期的「日」重复，**当月没有该日时自动取月末**（首次日期 31 日 → 2 月记 28/29 日，4 月记 30 日）。
- **待确认清单（不自动入账）**：到期只生成「待确认」项，**点确认（可改金额）后才写入流水**，也可以「忽略本期」。
  续费涨价时用「改金额后确认」，只影响这一期，规则金额不变。
- **幂等 / 多设备不重复**：待确认项与生成流水的 ID 都是 `rr-<规则ID前8位>-<yyyyMMdd>`，
  重复生成不会重复；两台设备各自确认同一期，同步后也只会留下**一条**流水。
- **跨设备共享规则**：规则随同步接口下发（`/api/sync/push|pull` 新增 `recurringRules[]`，LWW + 软删除墓碑）；
  待确认项只存本机，所以**不启动后端也能用**，只有跨设备共享规则时才需要后端。
- **入口**：手机端「设置 → 周期记账」（记账页顶部会提示「有 N 笔周期记账待确认」）；电脑端左侧导航新增「周期记账」，侧边栏显示待确认数量。
- 删除规则是软删除（会同步），同时清掉它尚未确认的待确认项；**已入账的流水不受影响**。

详见 [docs/RECURRING.md](RECURRING.md)。

### 修复

- **修复（手机端）：重置分类 / 重置账户后默认数据不回来。**
  重置的第一步会把现有分类、账户软删除（保留行作为同步墓碑），第二步写回默认数据时用的却是普通 `INSERT`；
  默认数据的 `client_id` 是固定的（`cat-food`、`acc-cash` 等），主键已存在就每条都插入失败，而 Android 的 `db.insert()` 失败是**静默**的，
  结果默认数据一条都没回来、界面看着像「全被删了」。现改为 `INSERT ... ON CONFLICT(client_id) DO UPDATE`：
  已存在的行会被**复活**（`deleted` 置 0、刷新 `last_modified` 以在 LWW 中胜过其它设备的旧删除墓碑），名称/图标/类型修正为默认值，`created_at` 保留；
  用户自建的分类/账户仍保持删除状态。
- **修复（手机端）：默认数据自愈。** 若「未删除的支出分类 / 收入分类 / 账户」一个都不剩（旧版本重置后只剩墓碑的情况），
  打开应用时会自动补回内置默认数据 —— 旧版本中招的设备**覆盖安装后重开一次即可恢复**。
- **修复（电脑端）：左下角版本号一直显示 v0.1.0。** 该标签在 `main.fxml` 里是**写死**的，与打包版本无关；
  现改为运行时读取打包元数据（jpackage `app-version` / 清单 `Implementation-Version`），以后每次出包自动显示正确版本。
- **修复（电脑端）：删除分类/账户后重启会被当成首次安装。** 「表是否为空」改为只统计未删除（`deleted=0`）的行。

### 改进

- **环形图标签回到扇区内居中显示（两端统一口径）**：每个扇区正中两行水平居中，第一行**金额（黑字加粗，带「元」）**，
  第二行**分类名（白字，带淡淡描边以适配浅色扇区）**；不外移、不引线、不显示占比。扇区较窄时按扇区可用宽度自动缩字号（有下限），
  只有极窄扇区（约 1–2%）才用引线放到环外兜底；同时修正了不同分类金额相同时标签名张冠李戴的问题。
- **账户初始余额口径统一（电脑端）**：「重置账户」恢复默认账户时保留原有初始余额，只把名称、图标、类型修正回默认值。
- **重置提示更明确（手机端）**：确认框列出将恢复的默认清单，完成后提示「已恢复 10 个支出分类、4 个收入分类」「已恢复 5 个默认账户」。
- **手机端周期规则表单更易用**：「类型 / 分类 / 账户」三行做成带边框与强调色竖条的卡片式按钮。

### 默认数据清单（两端一致）

- 支出分类：餐饮、交通、购物、住房、通讯、医疗、教育、娱乐、人情、其他
- 收入分类：工资、副业、红包、其他收入
- 默认账户：现金、储蓄卡、信用卡、微信、支付宝

## 升级提示

- 手机端：`versionCode` 已递增到 `4`，可直接覆盖安装（不会清数据）；也可在应用内「设置 → 检查更新」升级。
- 电脑端：下载新的免安装包解压替换即可 —— 数据存放在用户目录 `~/accounting`（H2 数据库与配置），**不会因替换程序而丢失**。
- 数据库结构：手机端本地库 `1 → 2`（只新增周期记账的两张表，保留既有账本数据）；电脑端为建表时 `CREATE TABLE IF NOT EXISTS` 自动补表；云端新增 `recurring_rule` 表。
- 兼容性：未改动同步协议既有字段，旧版本客户端可继续使用；后端需要升级到本版本才能同步周期规则。
