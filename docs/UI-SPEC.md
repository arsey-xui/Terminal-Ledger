# 多端 UI 布局（B 方案 + 修正）

## 手机端（Android，Material Design）

- **启动默认进入快速记账页**：数字键盘、分类快捷图标、语音入口。
- **底部 Tab 栏**：
  - 记账（默认）
  - 报表（概览卡片 / 分类饼图 / 趋势线 / 预算进度 / 热力图）
  - 设置（后端地址 / 立即同步 / 导出 / AI 分析）

## 电脑端（JavaFX，清爽扁平）

- **启动默认进入仪表盘（报表中心）**，大屏展示所有图表。
- **左侧侧边栏**：
  - 仪表盘
  - 记账入口
  - 账户管理
  - 预算管理
  - 数据管理（同步 / 导出 / 备份恢复 / AI 分析）

## 风格

- 主色 `#3F51B5`，辅色 `#FF5722`。
- 卡片式扁平、浅灰背景、圆角面板。
- 兼顾大字可读性与信息密度。
