# v1.1.0

个人双端同步记账系统 —— **离线优先、双端同步**（Android 手机端 + JavaFX 电脑端 + Spring Boot 云端同步服务）。

本次是**较大的功能版本**：手机端补齐了截图记账、应用内更新、AI 分析与离线语音输入；电脑端补齐了分类删除、一键重置、AI 设置入口与检查更新；两端统一了图表口径与交互细节。

## 本次更新（v1.1.0）

### 手机端

- **新增：截图记账**——相册选一张微信/支付宝/银行短信的账单截图，**端上离线 OCR**（ML Kit 中文识别，不需要联网、不依赖 Google Play 服务）自动读出金额与商户，弹出确认框后**自选分类与账户**再入账；识别不到金额会明确提示，可手动补。APK 增大到约 12.5MB（OCR 模型已内置）。
- **新增：应用内检查更新**——「设置 → 检查更新」**直接读取 GitHub Releases**（不需要后端在线）；发现新版本可**一键下载并调起系统安装界面**，并会自动引导开启「安装未知应用」权限。更新源（GitHub 仓库）可在设置里修改，结果带 6 小时缓存。
- **新增：AI 消费分析（离线可用）**——报表页新增「AI 消费分析」：默认用**内置规则引擎**（纯本地，解读本月收支、环比、最花钱的分类、预算预警），也可填入自己的 API Key 改用大模型；旁边「设置」可**随时**改 Key 或一键切回规则引擎。
- **新增：分类与配置一键重置**——「设置 → 数据管理」新增重置分类 / 重置账户 / 重置预算，恢复到初次安装的状态（软删除、可同步；**流水记录不受影响**）。
- **改进：管理分类列表排序**——支出分类整体排在收入分类之前，一眼分清收支。
- **改进：分类框统一等高等宽**——记账页分类按钮改为统一高度、文字居中，未设 emoji 的分类不再错位。
- **改进：近 30 天曲线口径**——由「净支出（支出−收入）」改为**只统计支出**，标题、图例、点选提示同步更新。
- **改进：环形图标签**——分类名与金额改为**每个扇区正中水平居中**（金额黑字、分类名白字，金额带「元」），并修正不同分类金额相同时**标签名张冠李戴**的问题。
- **改进：语音记账改为系统输入法语音 + 文本解析**——不再自研语音识别（原方案在部分机型上不可用甚至闪退），改为用输入法麦克风说话转文字，再由应用解析出金额与分类，**并移除了 RECORD_AUDIO 权限**。

### 电脑端

- **新增：删除分类**——记账页支持删除支出/收入分类（软删除、可同步），删除前会提示该分类下有多少条流水；历史流水保留并显示为「未分类」。
- **新增：一键重置分类 / 账户 / 预算**——数据管理页新增三个重置按钮，恢复到初次安装状态，流水不受影响。
- **新增：AI 设置入口**——以前只在首次启动时问一次 API Key，现在「数据管理 → AI 设置」可随时修改 Key、切换大模型或一键改回规则引擎。
- **新增：检查更新**——「数据管理 → 检查更新」直接读取 GitHub Releases；发现新版本可**打开下载页**（失败时自动复制链接到剪贴板）。免安装目录无法自动覆盖，需下载后手动替换。
- **改进：近 30 天曲线口径**——同样改为**只统计支出**（标题、Y 轴、悬浮提示同步更新）。
- **修复：重置预算后无法再设置预算**——重置会把旧预算软删除成墓碑，而保存预算时没有把 `deleted` 置回 0，导致「重置后重新设置却不生效、仪表盘一直显示暂无数据」；现已修复，并在预算管理页新增**已设预算列表**，保存/重置后可立即看到结果。

### 后端

- **新增：`GET /api/version`**——供客户端检查更新，返回最新版本、下载地址、更新说明与来源标记（`github` / `config`）。
- **新增：GitHub Releases 自动获取版本**——配置 `APP_GITHUB_REPO` 后，后端自动从仓库最新 Release 读取 tag（版本号）、正文（更新说明）与资产（下载地址）；查询失败自动回退到本地配置。
- **修复：AI 分析引擎标记**——请求大模型但未配置 Key（或调用失败）时会回退规则引擎，原来仍标注 `LLM`，现按**真正生效的引擎**返回。

> 说明：客户端的检查更新已改为**直连 GitHub**，因此**不启动后端也能检查更新**；后端的 `/api/version` 保留给需要统一管控版本的场景。

## 升级提示

- 手机端：可直接覆盖安装（版本号已递增到 `versionCode 2`）；也可在应用内「设置 → 检查更新」升级。
- 电脑端：下载新的免安装包解压替换即可 —— 数据存放在用户目录 `~/accounting`（H2 数据库与配置），**不会因替换程序而丢失**。
- 兼容性：本项目延续离线优先与 LWW 增量同步机制，首次同步前建议先做一次加密备份（电脑端「数据管理 → 导出加密备份包」）。
