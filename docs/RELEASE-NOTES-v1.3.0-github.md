# v1.3.0

个人双端同步记账系统 —— **离线优先、双端同步**（Android 手机端 + JavaFX 电脑端 + Spring Boot 云端同步服务）。

这个版本的重点是**把 AI 消费分析做成两端可用、离线也能降级的完整能力**，并系统性补齐深色模式、交互动效与图表可读性。

## 本次更新

### 🤖 AI 消费分析（两端 + 后端）

报表页点「AI 消费分析」，得到一段关于本月消费的文字分析。

- **双引擎，离线可用**：没配 API Key 时走**本地规则引擎**，完全离线、不出网、立刻出结果；配了 Key（OpenAI 兼容接口）则改用大模型增强。两条路径输出结构一致。
- **三个按天统计的口径**：给出**本月日平均支出、日支出标准差、日支出中位数**。
  - 口径是**按天聚合后再统计**：先把本月每天的支出加总，对这一天序列取平均、标准差、中位数。
  - **标准差**反映波动程度：数值大说明这个月花得不均匀。
  - **中位数**不受极端值影响：明显低于平均值时，说明少数几天拉高了整体。
- **自定义提示词（两端都有入口）**：可改成自己的分析口径（例如「只关注餐饮和交通」）。留空恢复默认。自定义内容不影响本地规则引擎。
- **截图记账的字段识别**：把账单 / 支付截图里的金额、分类、账户、备注、日期识别出来填进表单。图片压缩后再上传以控制体积与成本；**保存与否仍由你决定**。
- **Key 安全存储**：手机端用 Android Keystore 加密后落盘，不以明文写在配置文件里。

### 🌙 深色模式（手机端）

按「近黑、跟随系统」的取向做的完整配色，不是简单反色。

- 手机端可在「跟随系统 / 浅色 / 深色」之间切换。电脑端这一版**没有**深色模式：`app.css` 只有一套浅色主题。
- **图表适配**：饼图调色板按亮度排序保证相邻扇区对比；环形图默认的白色洞改成跟随页面底色；扇区标签颜色按**扇区实际亮度**自动选（用 WCAG 对比度取更优的那个候选色）。
- 对话框、日期选择器、状态栏图标一并适配，不再出现「深色界面里蹦出一个白框」。

### ✨ 交互动效（两端）

按「机械、利落、可预期」的取向做，不做弹性回弹和柔和缓动。

| 交互 | 手机端 | 电脑端 |
| --- | --- | --- |
| 按钮按下 | 填充瞬时反转（黑底 + 酸橙绿字）+ 下沉缩放 | 按下深色底 + 酸橙绿字；悬停白底 + 描边 |
| 底部导航 | 指示条平移 180ms；按压压暗；选中脉冲 | 选中态填充 + 左侧刻度；悬停预告 |
| 页面切换 | **推拉式**：新旧两页并排位移 | 内容淡入 + 轻微滑入 |
| 图表生长 | 按数据扫开 / 从底部升起，800ms | — |

- **去掉了 Material 的圆形水波纹**：与直角工业语言不搭。按压反馈改由「填充反转 + 图标脉冲」承担。
- **推拉方向按标签索引增减决定**：往右切时旧页向左推出、新页自右推入；往左切反过来。重复点同一个标签不再重放动画。
- 图表生长用 800ms 而不是其余动效的 200~300ms：环形图扫开是覆盖整块画布的连续变化，时长短会被看成「一下就位」。

### 📊 图表可读性

- **环形图标签避让**：外围标签原先会重叠（相邻小扇区的金额被压住看不见），现在自动排布让位。
- **网格线统一**成 1px 细线，不再用库默认的虚线灰网格。
- 无数据时的占位支持多行文案；标签已含金额与分类名，冗余图例隐藏。

### 🧹 空状态与首次使用

- 报表、流水、预算、记账四个界面都有明确的空状态说明。
- 记账页在**一笔流水都没有时**显示引导卡片，有数据后自动收起。

### 🔧 修复

- **后端 `LocalDateTime` 反序列化失败**：手机端写入 ISO 字符串、部分旧数据是毫秒时间戳，严格解析直接抛异常。改为宽松反序列化器，两种格式都接受。
- **手机端本地库缺组合索引**：数据库 `1 → 3`（`2` 新增周期记账表，`3` 补 `idx_txn_cat_date`、`idx_txn_acct_date`），报表按分类/账户聚合不再全表扫描。增量升级，保留数据。
- **两端同步时间字段格式不统一**，导致同一笔记录在两端表现不一致。统一为毫秒时间戳口径。
- **电脑端导出 / 备份加密口径**与手机端对齐。

## 升级提示

- **手机端**：`versionCode` 已递增到 `5`，可直接覆盖安装（**不会清数据**）；也可在应用内「设置 → 检查更新」升级。
- **电脑端**：下载新的免安装包解压替换即可。数据存放在用户目录 `~/accounting`（H2 数据库与配置），**不会因替换程序而丢失**。
- **数据库结构**：手机端本地库 `1 → 3`，两段都按 `oldVersion` 增量执行，保留既有账本数据；电脑端建表时自动补表。
- **兼容性**：未改动同步协议既有字段，旧版本客户端可继续使用。
